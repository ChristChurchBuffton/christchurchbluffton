Subject: New: Church Admin Panel — What It Is and How to Use It

Hi all,

I've set up a private admin panel for the church website. It's a simple online tool where you can manage things like prayer requests, newsletter signups, upcoming events, and photos — all in one place, without needing to touch any code or ask me for changes every time.

You can get to it here: christchurchbluffton.org/admin

**What it does:**
- Keeps a running list of everyone who's signed up for the newsletter or reached out through the contact form
- Collects prayer requests people submit on the website — including ones people leave anonymously — so nothing gets missed
- Lets you list upcoming events and volunteer sign-ups
- Lets you update photos on the site
- Keeps track of church staff and members

**Who has access:**
Each of you has your own private login, and everyone's set to Admin access, so you'll be able to see and manage all of it.

**Getting started:**
You'll get a separate email with your login and a temporary password. The first time you sign in, it'll ask you to set your own password — after that, it's yours to use going forward.

If anything's confusing or doesn't work the way you'd expect, just let me know and I'll take a look.

Kevin
